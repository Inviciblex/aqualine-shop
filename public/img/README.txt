Фото товаров (самохостинг).

Файлы вида <id>-<n>.webp — фото товара с id, по порядку в галерее.
Их отдаёт nginx с того же origin (/img/...), внешний прокси не нужен.

Как пополнять:
  1) npm run fetch:images   — скачает фото из колонки images Google-таблицы
     в этот каталог (WebP), пропустит мёртвые ссылки и напечатает готовые
     строки для вставки.
  2) вставьте напечатанные пути /img/<id>-<n>.webp в колонку images таблицы;
  3) закоммитьте новые файлы public/img/.

В колонке images таблицы несколько фото разделяются вертикальной чертой «|».
